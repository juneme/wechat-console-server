请在当前腾讯云服务器上完整部署本目录中的“微信公众号控制台”。

要求：
1. 先阅读 INSTALL.zh-CN.md，不要覆盖或删除服务器上的现有网站。
2. 部署目录固定为 /www/docker/wechat-material-uploader。
3. 检查并补全 .env 中的 ADMIN_USERNAME、ADMIN_PASSWORD、PUBLIC_BASE_URL、AI_API_KEY、PUBLISH_API_KEY、TEMP_API_KEY 和 CREDENTIALS_ENCRYPTION_KEY；密钥留空时允许 install.sh 自动生成。WECHAT_APP_ID、WECHAT_APP_SECRET 可在部署后通过控制台配置。不要把任何密钥输出到日志或聊天中。
4. 执行：cd /www/docker/wechat-material-uploader && bash install.sh
5. 验证：docker compose ps；curl -fsS http://127.0.0.1:8787/healthz
6. 在宝塔中新建独立站点，把域名 HTTPS 反向代理到 http://127.0.0.1:8787，请求体限制至少 32m，超时至少 120 秒。
7. 验证临时托管：上传一张测试图，确认处理后严格小于 1MB、返回公网 URL 与 expires_at，公开 URL 可读取；确认首页刷新后仍显示历史图片。
8. 若配置了微信密钥，确认服务器公网 IP 1.14.1.207 已加入微信公众号 API 调用 IP 白名单，并按 API.zh-CN.md 验证 /api/v1/wechat-images 返回 filename、url、size 和 uploaded_at。
9. 最后只汇报容器状态、健康检查、访问域名、三个 API 是否可用和仍缺少的配置，不显示任何 AppSecret、API Key、加密主密钥或管理密码。

如果构建失败，先查看完整错误并重试。Dockerfile 已使用腾讯云 PyPI 镜像；不要执行 docker compose down -v，以免删除数据库卷。
